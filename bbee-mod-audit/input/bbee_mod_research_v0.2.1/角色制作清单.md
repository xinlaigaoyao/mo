# 新角色制作清单

2026-10-15｜研究包 v0.2.1｜文档补充，不新增构建或游戏内验证。

## 目标与现状

用户目标：制作《苍翼：混沌效应》人物 Mod。暂按“独立可选角色＋自定义招式＋一个特色机制”规划；具体人物与玩法尚未确定。

已有 Zenith 框架、Ruby/Nine/Party 案例、动作链研究与单字段补丁。既有记录仅证明相应静态检查和离线组合通过；**完整新角色、素材导入及本地游戏运行尚未验证。**

## 还差什么、由谁推进

| 缺口 | 需要落实 | 分工 |
|---|---|---|
| 角色方案 | 人物/外观参考、武器、核心机制、首版范围；暂不要求精确数值 | 用户定方向，开发侧转为动作与机制规格 |
| 动作素材 | 选已有素材、原创制作或临时占位；立绘不能代替动作序列 | 用户确认来源/制作安排，开发侧列动作清单并适配导入 |
| 游戏基线 | 平台、实际 build、其他 Mod、现成角色是否能运行 | 用户本地测试并回传，开发侧比对版本与日志 |
| 独立工程 | 独立标识与资源路径；选择入口、基础状态、输入、判定、伤害及特色逻辑 | 开发侧实现；不能只给案例改名 |
| 运行闭环 | 完整构建、安装、战斗、重开、回退；不能只看语法与打包结果 | 用户执行实机测试，开发侧诊断修复 |

开发侧指后续助手/代码实现工作；目前没有可用的游戏实机测试环境。

**素材约束：**现有 BBTAG 导入链不是任意 PNG 导入器，原创帧素材需适配图集、网格、帧时长、原点/挂点及引用。临时素材可验证机制，正式动画替换后仍需重调判定与节奏。公开发布前核查素材来源与使用条件。

## 首版验收（建议范围，尚未锁定）

先完成独立选择入口、待机/移动、跳跃/落地、闪避、受击/倒地起身/死亡、一条短普攻连段和一个特色技能。每个必要状态需有动画或明确的临时替代。

验收链：**构建 → 安装 → 选角 → 移动/受击/命中 → 切场景 → 战斗结束或死亡 → 重开 → 正确回退。**特色状态须检查中断、死亡和切场景后的清理/恢复。

完整潜能/成长/传承、自定义界面、语音、多形态与复杂演出按设计另排；首版不默认全做。最终仍需兼容与卸载测试。

## 下一步

顺序：现成角色验证环境 → 受控单字段修改 → 独立角色原型 → 正式素材与招式扩展 → 发布前测试。

先确认：**做谁、核心特色、有没有动作素材。**随后提供平台、build 与运行结果；必要时补 `inspect/game_build.txt`、生成后的 `mod.json`/`gen`、相关表/脚本及安装日志。无需账号、整个游戏包或完整个人存档。

测试前保留独立存档备份；关闭角色可能清理角色记录，删除文件夹不等于安全卸载。不必等原帖找回或先学完整套 Unity 才开始，但不能跳过本地验证。
