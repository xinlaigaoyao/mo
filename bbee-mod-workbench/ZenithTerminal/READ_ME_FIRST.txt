THE ZENITH TERMINAL 0.3.0 (alpha)
A mod loader for BlazBlue Entropy Effect (Steam, Windows 10 or 11).

Unofficial fan project. It isn't made, endorsed or supported by 91Act or Arc System Works.
It unlocks no paid content. It holds no files of BlazBlue Entropy Effect.
Two of the characters that come with it are alpha builds that carry files of other games,
so that you don't need those games. Ruby Rose carries the BlazBlue Cross Tag Battle files
she is built from (BlazBlue Cross Tag Battle belongs to Arc System Works; Ruby Rose and
RWBY belong to RWBY's rights holders). DELTARUNE: Party carries the DELTARUNE sprites,
sounds and font it uses and its portrait artwork (they belong to Toby Fox and the
DELTARUNE team; the portrait artwork is by Temmie Chang).


THIS FOLDER

This is the Terminal's own folder. ZenithTerminal-0.3.0-alpha.exe, the file you
downloaded, made it and opens it. ZenithTerminal.exe in here opens it too.
If you unzipped ZenithTerminal-0.3.0-alpha.zip instead, this is that folder: keep it in
a place of its own, not inside Program Files and not inside the game's folder.

Don't move or rename this folder while mods are installed. Ruby's and Kris's sounds are
loaded from it.


START

1. Close the game.
2. Open the Terminal: the file you downloaded, or ZenithTerminal.exe in this folder.
   Windows may show "Windows protected your PC" because the file isn't signed:
   choose More info, then Run anyway.
   If the exe is blocked on your PC, "Start The Zenith Terminal.bat" opens the same window.
3. Press SET UP AND INSTALL, the large button at the bottom.
   The first time takes several minutes: it reads your game's data once and makes
   Ruby Rose's moves, art and sounds on your PC.
4. When the button says PLAY, press it, or start the game from Steam.
   Nine the Phantom, Ruby Rose and Kris are at the end of the Prototype list.

There is nothing else to install and nothing to add. Python comes in the Interpreter
folder, and the three characters are in the Library, switched on.


BEFORE YOU DELETE THIS FOLDER

Uninstall first: Options > General > UNINSTALL EVERY MOD.
While a mod character is installed your save names that character, and the normal game
can't load a save that names a character it doesn't have. The uninstall cleans the save
and copies it first.
